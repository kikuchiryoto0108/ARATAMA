本リポジトリでは私の担当部分のソースコードのみ載せています。
・Result/collosionのトンネリング防止/BOSS/Gimmick/Audio/EnemyAI/stage基盤/input_manager/game_controller/動画再生

ゲームの概要としては、爽快感2dアクションゲームで、コントローラーでのみ操作可能です。


1. オーディオシステム
XAudio2とMedia Foundationで独自のサウンドエンジン組みました。
X-Macroでリソース登録を自動化してて、audio_def.hに1行追加するだけでenumもパス配列もBGMフラグも全部生成されるようにしてます。WAVとMP3は拡張子で自動判別してロード。
SEの多重再生はラウンドロビン方式のプールにしてて、同じSEを連続で鳴らしても音が途切れないように、SEごとに8個のSourceVoiceを循環で使ってます。
BGMはフェードイン/アウト/クロスフェードを自前で実装。音量はマスター×カテゴリ×個別の3階層で制御できるようにしました。

2. 衝突判定システム
動的オブジェクトと静的ブロックを分離して、毎フレームO(N²)じゃなくてO(N×M)に落としてます。敵vs敵とかギミックvsギミックは判定スキップ。
あとカメラ範囲内のオブジェクトしか更新しないようにして、画面外のコストもカット。プレイヤーvsギロチンみたいな特殊判定は専用処理書いて、上から落ちてきたときだけヒットするとかゲーム性に合わせて作ってます。

3. ボスAI — State + Strategyパターン
状態遷移と攻撃ロジックを完全に分けました。
State Patternで Wait → Normal → Charge → Special → Stunned → Defeated の状態管理。
Strategy Patternで攻撃を IBossAttack インターフェースに抽象化して、BossAttackManager がランダム選択する仕組み。通常攻撃5種・必殺技2種を独立クラスで実装してるんで追加もラク。直前と同じ攻撃を避けるロジックも入れてます。
仮面の破壊はコリジョン処理中に即実行するとクラッシュするんで、遅延破壊キューにためてフレーム終わりにまとめて処理してます。
撃破演出も STAGGER → PLAYER_MOVE → POSSESS_FLASH → SCREAM → DOOR_CLOSE → FADE_OUT でフェーズ管理。

4. 敵AI
PATROL → CHASE → ATTACK → COOLDOWN のステートマシンで動かしてます。
レイキャストで視線判定入れて、壁越しにプレイヤー見つけないようにしました。進行方向の足元チェックして崖から落ちないようにもしてます。
武器種別(KATANA/KANABO/BOW/SPEAR)ごとにパラメータ変えるだけで、同じAIコードで全然違うキャラ性出せるようにしてます。

5. すり抜け防止コリジョン
高速移動時のトンネリング対策で、X軸Y軸を分離して順番に解決してます。
移動範囲をbounding boxで囲んで範囲内のブロックだけ取得してるんで計算量も抑えてます。詰まったとき用に8方向の脱出位置探索して、一番近い安全地点にワープさせる処理も入れました。

6. ネットワーク連携
ランキング送信はGoogle Apps Script経由でやってます。WinInetでHTTPS GETしてて外部ライブラリは使ってません。
GASが script.googleusercontent.com にリダイレクトしてくるんで、302リダイレクトを手動で追跡する処理書きました。
スレッドで非同期ロードして、メインスレッドはローディングアニメ出すようにしてます。15秒タイムアウトでダミーデータにフォールバックするんで、通信失敗してもプレイ体験は崩れないようにしました。

7. 動画再生
Media FoundationでMP4のイントロ動画再生してます。
フォーマットはRGB32→YUY2→NV12の順で自動ネゴシエーション。YUV→RGB変換は手動実装で、ルックアップテーブル使ってクランプ高速化してます。

8. 入力抽象化
SDL3のゲームパッドとキーマウを統一インターフェースにまとめました。
Command構造体に正規化して、ゲーム本体は入力デバイスを意識しなくていい設計です。最後に使ったデバイスを自動判定して、UI表示とか攻撃方向に反映させてます。

9. データ駆動設計
X-Macroで音声リソース一元管理
DAMAGE_TABLEで武器×通常/特殊のダメージを2次元配列化
hardModeScaleで難易度ごとの攻撃間隔やHPを一括調整
